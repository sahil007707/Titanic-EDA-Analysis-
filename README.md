# 🚢 Titanic EDA Analysis

Explore the fascinating story of the Titanic through data! This project dives into the Titanic passenger dataset to uncover patterns behind survival rates using advanced Exploratory Data Analysis (EDA) and visualization techniques.

---

## 📂 Project Structure

- **Data Info**: Overview of the dataset and its key features  
- **Data Cleaning & Handling**: Dealing with missing values, data types, and feature engineering  
- **EDA & Visualization**: In-depth exploration of features, survival rates, and correlations  
- **Conclusions**: Insights derived from the EDA

---

## 🚀 Technologies Used

- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📊 Key Highlights

✅ Cleaned and transformed the Titanic dataset  
✅ Explored missing values and engineered new features  
✅ Performed rich visualizations to analyze survival patterns by gender, class, age, and more  
✅ Set the stage for further machine learning modeling
